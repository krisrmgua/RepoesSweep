# Code of Conduct

This project is for a menu-bar app and the people improving it. Be direct, assume good intent, and keep discussion on the code.

- Critique the change, not the person.
- Do not post credentials, tokens, private repository names, or the contents of a clone.
- Harassment, slurs, and personal attacks are not welcome.

Maintainers may edit or hide comments and close issues that break these rules. Report conduct problems through a GitHub issue or by contacting the maintainer.
